Java Proxy Server

Minimal Java HTTP/HTTPS routing server. Configure IP and port via CLI flags.

Made on: October 12, 2025
UI Mode: Dark Light Mode
Overview
  • Runs as single JAR: java -jar Proxy.jar — GUI launches without any key requirement
  • Configurable bind IP and port
  • HTTPS optional (provide keystore if needed)
Screenshots
Quick Start
  1. Download the JAR from the right panel.
  2. Run: java -jar Proxy.jar — GUI starts without any key.
  3. For HTTPS, append keystore flags: --keystore /path/keystore.jks
